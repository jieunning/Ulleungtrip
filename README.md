# 울릉트립 (ULLEUNG TRIP)

울릉도 여행 정보 사이트입니다. Netlify로 배포됩니다.

## 파일 구조

| 파일/폴더 | 내용 | 이런 걸 수정할 때 |
|---|---|---|
| `index.html` | 홈 (메인 페이지) | 홈 문구, 카드 이름·설명·가격 |
| `courses.html` | 추천 코스 | 코스 일정, 동선 설명 |
| `places.html` | 플레이스 (명소·맛집) | 명소/맛집 추가·수정 |
| `info.html` | 여행 정보 | 배편 시간, FAQ, 준비물 |
| `css/style.css` | 전체 디자인 (색상·글꼴·배치) | 색상, 크기, 간격 |
| `js/main.js` | 기능 (히어로 슬라이드, AI 비서 답변) | AI 답변 내용, 슬라이드 속도 |
| `images/` | 로고, 히어로 사진 | 사진 교체 (같은 파일명으로 덮어쓰기) |

## 수정 팁

- **문구 수정**: 각 `.html` 파일에서 해당 텍스트를 찾아 바꾸면 됩니다.
- **색상 변경**: `css/style.css` 맨 위 `:root`의 `--teal`(청록), `--navy`(남색) 값을 바꾸면 사이트 전체에 적용됩니다.
- **히어로 사진 교체**: `images/hero1.jpg`, `images/hero2.jpg`를 같은 이름의 새 사진으로 교체하세요.
- **AI 비서 답변 수정**: `js/main.js`의 `aiAsk` 함수 안에 키워드별 답변이 있습니다.

GitHub에서 파일을 열고 연필 아이콘(Edit)을 눌러 수정한 뒤 **Commit changes**를 누르면, Netlify가 자동으로 새 버전을 배포합니다 (약 30초 소요).
